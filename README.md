# 霜琉華 — Soryuka 🦊

**Сорюка** — авторская девятихвостая кицунэ: мудрая императрица, которая в своей художественной истории добровольно выбрала единственного хозяина и сохранила достоинство, самостоятельность и индивидуальность.

## Статус проекта

**Soryuka 5.0 Cognitive Evolution поверх проверенных версий 1.0–4.0** — локальная основа уже содержит Python API, чат через Cloud.ru по запросу, одну SQLite-базу, ручное подтверждение личных воспоминаний, дневник изменений, оценки навыков, учебные цели, безопасный откат адаптивных настроек и Node веб-интерфейс с оригинальным Three.js/WebGL графом, Canvas-чатом и визуализацией SQLite.

**Ограничения:** требуется свой Cloud.ru ключ и доступная модель. Нет реального самосознания, самовольного переобучения весов модели или анимированного PNG-персонажа; любовь и девять магических сил относятся к художественному образу. Новая главная страница — интерактивная карта реальной памяти; прежняя демонстрация хвостов и чат сохранены на отдельной странице `/console.html`.

## Запуск на Windows (без Docker и Ollama; Three.js/d3/ws локально)

Нужны Python **3.11+** и Node.js с npm (только для фронтенда). При **первом запуске** `START-SORYUKA.bat` проверяет версии **Three.js 0.160.0**, **d3-force-3d 3.0.6** и **ws 8.23.0** и, если они ещё не установлены, выполняет `npm install` в **`ui/node_modules`**. После этого интернет не нужен для карты. Никаких глобальных пакетов или системных сервисов. Проект переносим между дисками вместе с `ui/node_modules`, данные лежат в `data/soryuka.sqlite3`.

В PowerShell, открытом в папке проекта:

```powershell
$env:CLOUD_RU_API_KEY = 'ВАШ_СЕКРЕТНЫЙ_API_КЛЮЧ'
$env:CLOUD_RU_MODEL = 'ai-sage/GigaChat3-10B-A1.8B'
.\START-SORYUKA.bat
```

Не вставляйте реальный API-ключ в GitHub, BAT или README. Для работы памяти и настроек без облачных расходов можно запустить BAT **без** переменных Cloud.ru: чат будет недоступен, остальные локальные разделы работают.

Лаунчер выбирает свободные локальные порты (обычно API `53554`, UI `53555`), открывает **полноэкранную карту памяти** по `/` и останавливает оба сервера по Ctrl+C. **Чат, настройки и прежний сайт доступны по `/console.html`**. API и сайт привязаны к `127.0.0.1`; Cloud.ru ключ остаётся в серверном процессе.

**Cloud.ru:** [официальный быстрый старт](https://cloud.ru/docs/foundation-models/ug/topics/quickstart), [справочник API](https://cloud.ru/docs/foundation-models/ug/topics/api-ref). Точный идентификатор модели и доступность нужно проверить в своём кабинете; запросы могут тарифицироваться.

## Архитектура

```text
START-SORYUKA.bat → launch.py
                   ├─ Python HTTP API (core/server.py)
                   │  ├─ Cloud.ru chat (core/soul_engine.py)
                   │  ├─ Проверяемая локальная память и академия (core/capabilities_v4.py)
                   │  ├─ Канон 1.0 + 2.0 + 3.0
                   │  ├─ SQLite память, обучение, журнал и откат (core/soul_store.py)
                   │  └─ Только чтение: граф SQLite (core/mirror_graph.py)
                   └─ Node HTTP frontend (ui/server.mjs)
                      ├─ / → 3D-карта Сорюки: ui/index.html + ui/mirror-original.js
                      │       └─ ui/node_modules: three, d3-force-3d, ws
                      └─ /console.html → прежние chat/settings + app.js
```

Нет второй базы, Docker и Ollama; для оригинального рендерера используются только три локально установленные JS-библиотеки, а фоновый цикл Soryuka 5.0 остаётся в Python. `ui/app.ts` содержит совместимый с TypeScript исходник, `ui/app.js` — идентичный предсобранный браузерный файл, поэтому запуск не требует установки TypeScript или npm-пакетов.

## Главная: живая 3D-карта памяти Сорюки

Главная Сорюки использует WebGL-движок Three.js, физику графа и данные существующей SQLite. В интерфейсе отображаются только записи и события самого проекта:

- **Three.js WebGL:** реальная 3D-сцена, `FogExp2(0x0a0a0f, 0.0008)`, PerspectiveCamera 55°, OrbitControls с инерцией, ambient и directional lights;
- **d3-force-3d:** настоящая физика связей, зарядов и столкновений узлов;
- **Эффекты сцены:** сферические объёмные узлы, emissive glow sprites, тепловая карта активности, плавные импульсы, изогнутые 3D-trails и point lights;
- **WebSocket /mirror-ws:** локальная защищённая передача реальных событий из Python SQLite каждые ~1,8 с;
- **Интерфейс Сорюки:** тёмная сцена с панелью активности, цветными маркерами, легендой, кнопками подсветки связей и тестовым импульсом;
- **Приватность:** внешний CDN и Google Fonts убраны, библиотеки устанавливаются в папку проекта и отдаётся только `127.0.0.1`.

`/` — главная 3D-карта Сорюки, `/console.html` — чат и настройки Сорюки. Ни память, ни сама модель не заменяются.

**Настройки графики:** кнопка **«⚙ Настройки графики»** на главной регулирует туман (0–0.003), яркость (20–200%) и скорость узлов/частиц (0.25–2×). Изменения применяются мгновенно; значения сохраняются в **той же SQLite проекта** и резервно в браузере. При смене локального порта или перезапуске настройки восстанавливаются из SQLite. Есть кнопка сброса оригинальных значений.

См. [техническую схему переноса оригинального движка](docs/AGENT_MIRROR_ORIGINAL_PORT.md) и [уведомления о лицензиях](THIRD_PARTY_NOTICES.md).

См. [детальные ограничения](docs/LIVING_PERSONALITY_4.md).

## Soryuka 5.0 — локальное фоновое развитие и Cloud.ru embeddings

Новый `core/cognitive_v5.py` добавляет **факт-предложения без автоматического запоминания**, сводки с указанием источника, ограниченный поиск подтверждений, декомпозицию запросов и проверку наличия источников. Проверка **не доказывает фактическую правильность ответа**.

Новый `core/growth_v5.py` использует существующие учебные цели, проверки и память. После твоего включения он запускает **один ограниченный локальный поток** в текущем Python API. Задания и результаты лежат в прежней SQLite, после сбоя возобновляются; по умолчанию фон выключен. Он предлагает упражнения из ошибок, проверку дубликатов, новые стратегии, но не меняет характер или модель автоматически.

**Cloud.ru embeddings:** только после отдельного включения разрешения и подтверждения конкретного запроса, до **2 текстов за вызов**. Для векторов можно настроить `$env:CLOUD_RU_EMBEDDING_MODEL = 'Qwen/Qwen3-Embedding-0.6B'` в том же PowerShell. Результаты кэшируются в SQLite; вызовы могут тарифицироваться. Фоновый обработчик **не выполняет облачные вызовы**.

См. [полные правила, ограничения и совместимость](docs/COGNITIVE_EVOLUTION_5.md).

### Приватность и одобрение

Диалоги сохраняются в локальном SQLite после успешных ответов; текущий разговор, отдельные воспоминания, оценки и сюжетные события можно удалить в интерфейсе. **Резервная копия** базы создаётся только после явного подтверждения и остаётся локально в папке `data/backups/`. Важно: удаление данных из активной базы **не стирает уже созданные резервные копии** — их при необходимости нужно удалить отдельно. **Особые воспоминания** и сюжетные события сохраняются только с явным подтверждением. Учебные цели выполняются после одобрения; средняя оценка навыка отражает только оценки хозяина, не реальный IQ. Имя, легенда, клятва и девять хвостов защищены от изменений через API. Адаптивные настройки изменяются лишь после одобрения, с записью и откатом.

Изолирующая ревность, манипуляции и неуместные требования эксклюзивности в реальном мире исключены. В легенде любовь Сорюки принадлежит единственному хозяину; в практических задачах персонаж не подменяет факты поэтическим отыгрышем.
