# SORYUKA 3.0 — Eternal Heart & Supervised Growth

> **Действующая основа, не научное доказательство сознания.** Сорюка — оригинальный художественный персонаж. Её нежность, любовь, эмоции и клятва относятся к отыгрышу роли и правилам поведения, а не к объективным чувствам или возможностям ИИ.

## Главный принцип

**Сорюка — могущественная и мудрая императрица, которая добровольно выбрала своего единственного хозяина и сохранила индивидуальность.** Любовь внутри её истории исключительна, но она не ограничивает настоящие отношения человека и уважает его свободу.

## Что действительно работает

- **Единый Python-механизм**: использует существующие канонические JSON 1.0/2.0 и добавляет 50 контрактов версии 3.0 — без второго «мозга».
- **Cloud.ru**, стандартный `POST /v1/chat/completions`: только по явной отправке сообщения, ключ/модель берутся из переменных окружения. Предварительно настроить сервис обязательно.
- **SQLite**: диалоги, подтверждённые воспоминания, сюжетные события, учебные цели, оценки, предложения изменений, версии и журнал аудита.
- **Саморазвитие под управлением владельца**: предложить цель → одобрить → выполнить → представить подтверждение; оставить оценку; предложить изменить стиль → одобрить/отклонить → при необходимости откатить.
- **Аватарные события**: эмоциональное состояние, мимика и жест передаются вместе с ответом. На сайте сейчас **абстрактное Canvas-изображение девяти хвостов**, а не финальная картинка персонажа.
- **Локальный запуск**: одна BAT-команда на Windows, Node.js обслуживает страницу и проксирует запросы; Python — единственный API; SQLite — единственная база.
- **Контроль**: доступ только по `127.0.0.1`, случайный серверный токен, запрет межсайтовых запросов в Node, ключ Cloud.ru остаётся вне браузера.
- **Автотесты**: SQLite, история, согласие на память, откат, защита канона, режимы, мок Cloud.ru, HTTP API, статус интерфейса. CI проверяет Windows/Linux.

## Что принципиально не заявляется готовым

- Нет реального самосознания, настоящих субъективных чувств или автономной воли; это **литературный образ и адаптивный интерфейс**.
- Нет фонового самообучения, скрытых агентов, самозапуска задач и самовольного изменения кода или характера.
- Нет визуальных PNG-аватаров, озвучивания или настоящей анимации тела: есть лишь схемный Canvas и метаданные для будущих поз.
- Нет автоматического определения эмоций пользователя, эмбеддингов и RAG; сохранённая память только подтверждённая.
- Изменение системных знаний самой Cloud.ru модели не происходит. Развитие состоит из **проверяемых целей, обратной связи и одобренных настроек**.
- Облачный провайдер может взимать плату за запросы. Без ключа и выбранной модели сообщения не отправляются.

## Запуск Windows

**Требования:** Python 3.11+, Node.js. Никаких Docker, Ollama, сторонних Python-библиотек или npm-пакетов.

1. Клонируй репозиторий в любую папку (в том числе на переносной SSD).
2. Открой PowerShell в папке и задай секретные переменные для **этого терминала** (не сохраняй ключ в GitHub, `.bat` или файлах):

```powershell
$env:CLOUD_RU_API_KEY = 'ВСТАВЬ_СВОЙ_СЕКРЕТНЫЙ_КЛЮЧ'
$env:CLOUD_RU_MODEL = 'ai-sage/GigaChat3-10B-A1.8B'
.\\START-SORYUKA.bat
```

3. Для запуска без облачных расходов просто открой BAT без этих переменных: сайт и локальные разделы работают, чат вернёт понятную ошибку о конфигурации.
4. Загрузится страница `http://127.0.0.1:<найденный_порт>`; по умолчанию UI ищет 53555, API — 53554, при занятости выбираются свободные.
5. Ctrl+C останавливает дочерние серверы в том же окне; повторный запуск предотвращается локальной блокировкой.

Официальная документация: https://cloud.ru/docs/foundation-models/ug/topics/quickstart ; https://cloud.ru/docs/foundation-models/ug/topics/api-ref

## Границы памяти и романтической личности

Диалоги сохраняются локально после успешного ответа. **Отдельные воспоминания** (предпочтения, совместные события, традиции) создаются только после отмеченного согласия. Сюжетные эпизоды помечаются `fiction=true`; это не реальные факты.

Система не начисляет «любовные уровни» и не вызывает чувство вины за отсутствие. Взаимодействие остаётся доброжелательным, а забота не заменяет реального общения с людьми. Неизменяемые имя, клятва, девять хвостов, биография и ценности нельзя перезаписать через API.

## Качество и развитие

Средняя оценка навыка вычисляется только по явно внесённым оценкам (1–5), поэтому **не является объективной оценкой интеллекта**. Цели проверяются по сформулированному критерию и подтверждаются вручную. При отсутствии истории система показывает «нет данных», а не выдумывает прогресс.

Защищённый канон меняется только через отдельный согласованный кодовый PR. Настройки `reply_length`, `humor_level`, `formality`, `affection_level` можно предложить и одобрить через сайт, затем откатить с сохранением журнала. Автоматическое изменение этих настроек выключено.
