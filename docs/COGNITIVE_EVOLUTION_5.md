# Soryuka 5.0 — Cognitive Evolution & Supervised Local Growth

> Выбранный объём: **ровно 32 пункта** (1, 2, 3, 4, 5, 8, 9, 11–18, 21, 25, 28, 30, 31–40, 42, 44, 47). Остальные пункты из предложенного списка не выбирались. Техническая очередь SQLite включена как необходимая внутренняя основа для 21/30, но отдельного независимого агента не создано.

## Принципы

**Сорюка — мудрая могущественная девятихвостая императрица, добровольно выбравшая хозяина при сохранении собственного достоинства.** Любовь, клятва и собственная «душа» персонажа относятся к художественному образу, не являются доказательством реальных чувств или сознания модели.

**Одна локальная архитектура:** Python API + существующий `core/soul_engine.py` и `core/soul_store.py`, таблицы **в прежней SQLite**, Node.js только локальный фронтенд. Без Docker/Ollama/новой локальной LLM/новых pip и npm-зависимостей. Прежний canon v1/v2/v3/v4 не переписывается.

## Что работает локально без Cloud.ru

- Короткие extractive-сводки с указанием сессии; **сохранение только по подтверждению**, оригинальные сообщения остаются в истории.
- Предложения выделения фактов из некоторых русских фраз («я люблю», «мне нравится», «я предпочитаю», «мы решили»). **По умолчанию выключено**; выводится в ответ, **не сохраняется в память**, пока владелец не нажмёт сохранение.
- Многошаговый план: ограниченная декомпозиция вопроса, точечный поиск по существующим подтверждённым записям и связям, осторожная пометка наличия источников. Это не эквивалент полноценного автономного рассуждения LLM и не независимая проверка истинности.
- Подтверждённые человеком причинные связи, без автоматической подмены корреляции причинностью.
- Фоновая очередь **в той же SQLite**: поиск предложений о похожей памяти, учебные упражнения из реально ошибочных контрольных и рекомендации из предыдущих оценок. По умолчанию выключена; после включения выполняется в Python-потоке **только при запущенном локальном приложении**.
- Фоновые задания ограничены двумя за один цикл, тремя попытками и коротким временем работы. После сбоя просроченные задания возвращаются в очередь. Ни память, ни стратегия, ни канон **автоматически не заменяются**.
- Стратегии 4.0 используют прежний журнал решений; вариант с результатом не лучше исходного не допускается к утверждению. Перенос навыка — согласованная идея, **не изменение самой модели**.

## Embeddings Cloud.ru — отдельно и с явным разрешением

- В интерфейсе есть отдельный тумблер **«Разрешить ручные Cloud.ru embeddings»**. Он выключен по умолчанию.
- Сначала пользователь включает разрешение, затем **отдельно подтверждает** индексацию до 2 воспоминаний или поиск — каждый вызов может тарифицироваться.
- Запросы идут напрямую из локального Python, ключ остаётся в переменной `CLOUD_RU_API_KEY` и не отправляется в браузер.
- Endpoint: `https://foundation-models.api.cloud.ru/v1/embeddings`. Модель по умолчанию `Qwen/Qwen3-Embedding-0.6B`, меняется через `CLOUD_RU_EMBEDDING_MODEL`; доступность модели зависит от Cloud.ru.
- Векторы и SHA-256 текста хранятся в локальной SQLite; повторный запрос к точно тому же тексту и модели может взять вектор из кэша. Результат — **косинусная близость**, не оценка достоверности и не подтверждение источника.
- После удаления воспоминаний ссылка на вектор удаляется каскадно; общая кэш-запись без текста может остаться. Для удаления всех артефактов рекомендуется управляемая очистка базы/резервных копий.
- Если интернет или API недоступны, прежний локальный текстовый поиск версии 4.0 остаётся доступен.

Источники API и списка моделей: [Cloud.ru — Foundation Models API](https://cloud.ru/docs/foundation-models/ug/topics/api-ref) и [обзор доступных моделей](https://cloud.ru/docs/foundation-models/ug/topics/overview__available__models).

## Разрешения и статус

| Разрешение | Исходное значение | Последствия включения |
|---|---|---|
| `background_local` | Выключено | Создание ограниченных локальных заданий, пока запущен Python API |
| `fact_suggestions` | Выключено | Только предложения в ответах чата, без автоматического запоминания |
| `cloud_embeddings` | Выключено | Возможность явного платного запроса embeddings; фон не обращается к облаку |

Вся очередная работа хранится в **той же SQLite**. Основной канон и защита исторической легенды неизменны. Закрытие программы останавливает поток; после запуска он может возобновить задачи, только если разрешение осталось включено. Для остановки достаточно отключить `background_local` или закрыть локальный сервер.

## Реалистичная трактовка саморазвития

Это эволюция *прикладных методов*: пользовательские оценки, ошибки, эталонные тесты, предложения новых стратегий, основанные на источниках обучающие задания и изменения после одобрения. **Веса Cloud.ru-модели не меняются**. Система не исполняет собственный произвольный код, не редактирует себя, не делает фоновых API-запросов к LLM и не получает неограниченных прав.

Пример: владелец проверил китайское выражение, ответ не совпал с эталоном → локальный цикл предложил повторное упражнение → владелец проверил новую попытку → сравнил результат, одобрил изменение подхода. Отметка «одобрено» сама по себе не доказывает, что модель стала умнее.

## Уточнение границ

Проверка ответа означает **статическую оценку наличия подтверждённых записей**; она не подтверждает математически корректность всех утверждений. При отсутствии доказательств пометка будет «не проверено». Нельзя заменять это выдуманной уверенностью, показывать вымышленные уровни IQ или утверждать, что у ИИ появилось самосознание.
